# Turbo Bunny Blast Run

A fast, bouncy platformer for Kellan, Diana and Bernie. Captain Shellbottom's shellbots have swiped the five Golden Carrots! Hold a direction to build up speed, zap shellbots with the carrot blaster (or bop them from above), bounce on springs, float with your bunny ears, grab carrots, and beat the captain in Shell Castle. Falling just gets you a free bubble ride back from Bernie, so there is nothing scary.

Single-file HTML5 game — open `index.html`.
- Keyboard: arrows or A/D to run, Space/Z/Up to jump (hold in the air to float), X to zap.
- Touch: on-screen arrows, JUMP and ZAP buttons.
- Pick Kellan or Diana on the title screen; EASY has slower bots.
- Progress (golden carrots won) is saved automatically.

The characters, art, music and levels are all original. Inspired by classic fast side-scrolling run-and-gun platformers.

## Tests
`python3 tests/run.py` plays all 5 levels at both difficulties with a bot, plus fall, zap and real-time keyboard checks. `python3 tests/shots.py` makes screenshots.
